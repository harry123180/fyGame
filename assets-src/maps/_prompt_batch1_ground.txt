請用你的圖片生成功能（image generation），生成「八張」2D 像素風（pixel art）遊戲地板貼圖（tileable texture）。

① 這是什麼，跟之前不一樣
這是手機多人 PVE 小遊戲 fyGame 的關卡地板。遊戲是 2D 俯視角（正上方往下看，top-down）。
八個關卡像一趟旅程：草原 → 村莊 → 城市 → 沙漠 → 海灘 → 雪原 → 火山 → 天空神殿。
附圖是同一個遊戲已經定案的角色與 BOSS 像素精靈圖（洋紅背景只是去背用，跟這次無關），請沿用「同一種像素風」：
色塊乾淨、邊緣銳利、色盤精簡、明亮可愛的休閒遊戲色調。
之前生過的是「角色精靈圖」；這次要的是「地板貼圖」：整張填滿、沒有背景色、沒有角色、沒有主體物件，
會被程式縮成 256×256 後重複鋪滿 2400×1600 的地圖，角色（約 76px 大）會走在上面。

**地板最重要的是低對比、不搶戲**：顏色變化小、細節細碎，角色疊在上面要清楚；絕對不是高對比花紋。
八張要是同一個遊戲，但一眼分得出是哪一關。

檔案全部存在 C:\Users\user\Desktop\fyGaming\assets-src\maps\<檔名>（例如 C:\Users\user\Desktop\fyGaming\assets-src\maps\meadow\ground.png）。

③ 貼圖硬性要求（每張都要）
- 正方形 1024 × 1024
- **可無縫拼接（seamless tileable）**：左邊緣與右邊緣、上邊緣與下邊緣的圖案必須完全接得上，重複鋪 2×2 時看不出接縫
- 正上方俯視，沒有透視、沒有地平線、沒有天空
- **整張亮度均勻**：不要暗角（vignette）、不要中央打光、不要邊框、不要漸層
- 圖案細碎且均勻分布，**沒有任何單一顯眼的大物件**（不要整棵樹、大石頭、大坑、整棟建築），否則重複鋪時一眼看出重複
- 輸出不透明 PNG（RGB，不要 alpha 通道）

④ 像素風規格
- 每個邏輯像素放大成 8 × 8 的實心方塊（整張相當於 128 × 128 個邏輯像素），邊緣銳利，不要抗鋸齒、不要模糊、不要平滑漸層
- 每張色盤精簡（約 8～16 色）
- 跟附圖角色同一種像素顆粒感；所有張是同一個遊戲、同一種像素風

⑤ 不要做的事
- 圖上不要有任何文字、數字、字母、格線、標籤、浮水印、UI
- 不要寫實照片、不要 3D 渲染、不要等角（isometric）
- 不要角色、動物、人物、車輛
- 不要修改 C:\Users\user\Desktop\fyGaming\assets-src\maps 以外的任何檔案；不要動 MAPS_SPEC.md、stages.json

⑥ 步驟
1. 依序生成，存到上面的路徑（子資料夾已存在）
2. 圖片生成後如果在暫存位置，要複製到上面的路徑（每張只生成一次，不要自己重生多張）
3. 用 Python PIL 確認檔案真的存在，印出檔名、尺寸、mode、檔案大小
4. 如果某張生不出符合要求的，直接說哪一張沒成功、哪一項不符合，不要用不相干的圖充數。
5. 如果遇到用量上限（429 / rate limit / usage limit），立刻停止並回報已完成哪幾張，不要重試。
